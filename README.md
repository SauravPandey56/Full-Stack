🧠 Engineering Approach
I am following a simple progression:
1️⃣ Learn
Understand the underlying concept rather than only copying syntax.
2️⃣ Practice
Write small programs and exercises to reinforce the concept.
3️⃣ Apply
Use the concept in assignments and small projects.
4️⃣ Build
Combine multiple concepts into complete projects.
5️⃣ Improve
Refactor, debug, organize, and extend previous work as my skills grow.
This repository is therefore a record of implementation and progression, not just course completion.
